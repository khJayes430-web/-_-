# Kh Jayes — Digital Business Card

A mobile-first GitHub Pages digital business card.

## Setup

1. Upload `index.html`, `style.css`, and `script.js` to your GitHub repository.
2. Replace the placeholder social links in `index.html`.
3. Replace the avatar placeholder with your photo if desired.
4. Enable **GitHub Pages** from the repository's Pages settings.
5. Use the resulting GitHub Pages URL for your NFC card.
